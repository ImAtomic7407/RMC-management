RMC Local Installer Package

1. Run Install_RMC_Local.cmd
2. Pick an install folder
3. Launch Start_RMC_Local.cmd from the installed folder

The package includes the app code, server dependencies, and the current database/data seed.
It still requires Windows and Node.js to run the local server.
